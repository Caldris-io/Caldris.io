## Caldris (wound down)

Caldris was building compliance-ready audit trails for AI agents. The project was wound down in October 2026, and caldris.io now redirects to [humaine.studio](https://humaine.studio).

The M0 demo slice (a Claude Code evidence-layer plugin) is preserved in [`product/`](product/). See `product/PLAN.md`, `product/README.md`, and `product/THREAT_MODEL.md`.
